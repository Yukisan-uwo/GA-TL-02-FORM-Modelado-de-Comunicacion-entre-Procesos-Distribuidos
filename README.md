## Instrucciones de compilación

Para compilar las notas de presentación, acceder a su carpeta y ejecutar:

```bash
pdflatex main.tex
biber main
pdflatex main.tex
pdflatex main.tex
```

El resultado es el archivo `main.pdf`.
